功能总览

自研轻量 SSH/SFTP 终端，参考 SecureCRT 使用体验，代码 100% 原创。（v4 线 · 随版本持续增强，最新更新见更新日志）

# 连接与会话

⌨ 多标签 SSH 会话

一个窗口管理多台服务器；密码 / 私钥 / keyboard-interactive 自动适配；会话按 主机+端口+用户名 去重保存。

📥 外部会话一键导入（v5.0.8）

从 Xshell（自动读取本机 .xsh 会话）、PuTTY（自动读取注册表 SSH 会话）、Termius（导出 JSON）与 OpenSSH config 一键导入；自动去重、不含密码、按来源自动分组。

🔑 密钥登录与管理

一键生成 Ed25519 密钥对；密码连接一键安装公钥（权限/SELinux 修正 + 回读校验）；密钥失败自动诊断真实原因。

🛡 主机指纹校验

首次连接 SHA256 指纹确认（TOFU），后续严格比对，主机密钥变更即拒绝并提示更新——防中间人攻击。

♻ 断线自动恢复

keepalive 防空闲断开；断开后标签保留、按回车自动重连；转发配置随会话持久化，重连自动恢复。

⚡ v5.0 全新内核与安全（v5.0.0）

升级清单 Ed25519 非对称签名强制验签（公钥指纹官网公示）、升级异常自动回滚、Argon2id 密钥派生、崩溃日志本地留存——安全与可靠性的代际升级。

🪟 终端分屏与镜像（v5.0.0）

单/左右/上下/四宫格/自定义 1+2（左大右二小，v5.0.8）布局，分隔条拖拽调比例（持久化）、只读镜像窗格、快捷键循环布局与窗格焦点切换。

🎨 全新设计系统（v5.0.0）

Emerald 品牌色 + Design Tokens 全量 token 化、深浅双主题一键切换、34 个矢量线性图标、设置页卡片式分组导航、无障碍焦点环与 reduced-motion 降级。

🧩 效率三件套（v5.0.0）

全局命令面板 Ctrl+Shift+P（拼音首字母过滤）、脚本库宏（变量占位符 + 顺序执行）、传输队列暂停/恢复/优先级/限速。

🌐 网络与传输强化（v5.0.0）

SFTP 多 worker 管道化传输、断点续传（journal 跨重启）、可选限速、SOCKS5/HTTP CONNECT 代理、ProxyJump 跳板链（≤3 级复用已存会话凭据）。

🚀 启动性能（v5.0.0）

WebView2 数据目录原子切换 + 后台清理，窗口 1 秒级可见；升级完成时序加固（等待旧进程退出 → 自动启动新版 → 异常自动回滚）。

🔄 智能自动重连（v4.3.1）

意外断线按 2/4/8 秒指数退避自动重试 3 次，按回车随时接管；单实例运行，双开不再写坏配置。

🌐 多编码支持

UTF-8 / GBK / GB18030 / Big5 自动与手动识别，乱码服务器不再愁；按会话记忆编码设置。

📦 绿色便携 · 无缝升级

解压即用，不写注册表、免管理员权限，整个文件夹可拷走即用；3.x 旧配置原地升级无缝沿用。

# 终端体验

⇅ 工具栏/快捷指令行折叠（v5.0.12）

快捷指令行下方细条开关一键将功能行与快捷指令行缩回隐藏，终端区占满释放空间；箭头常显、悬停高亮；状态持久化，重启保持；与侧栏折叠叠加使用终端区最大化。

⇔ 侧边栏一键收起/展开（v5.0.10）

点击会话列表与终端区交界的边界细条，左侧栏一键缩回隐藏，终端交互区即时占满全窗口；再次点击展开恢复，箭头随状态转向；收起状态记忆保存，重启保持；终端窗格与分屏布局自动重新适配占满。

🖥 现代终端内核

xterm.js 渲染、窗口自适应、256 色、窗口尺寸记忆；输出 16ms 合帧批量推送 + 32KB 阈值提前推送，高频输出不掉帧；UTF-8 多字节跨批保护不乱码（v4.3.0/v4.3.1）。

🔍 终端内查找

会话内快捷键唤起查找栏，向上 / 向下定位关键日志。

⚡ 快捷命令栏

自定义常用命令按钮一键发送，支持添加 / 编辑 / 删除。

🎨 5 款皮肤主题

深浅配色全局切换，自绘标题栏跟随主题。

🗣 界面多语言（v5.1.4 增强）

简体中文（默认）/ 繁體中文 / English / 한국어，一键切换即时生效。v5.1.4：重启后记住所选语言；界面翻译全面补全（工具栏/快捷命令/设置九个分组等 439 条）；切换语言实时生效（含切回中文）。

📋 智能剪贴板

选中即复制、右键粘贴；终端标题防伪造（OSC 注入防护由渲染层转义处理）。

# 文件传输（SFTP）

📁 远程文件管理

远程目录浏览、重命名、删除、新建目录、右键菜单操作、路径直达。

⬆ 上传 / 下载队列

多任务传输队列，实时进度、可取消；按服务器编码做文本转换传输。

📂 整目录下载

远程目录递归下载到本地，自动创建同名目录结构。

🚀 传输性能

256KB 分块流式传输 + 进度事件节流（100ms 或 ≥1% 增量），大文件传输界面不再卡顿（v4.3.0）。

🛡 传输通道强化（v4.3.1）

SFTP 通道按会话隔离（多标签互不串扰）+ 断线重连通道自愈 + 目录递归删除；4 并发闸门，批量传输不挤占带宽。

☑ 多选批量操作（v4.3.2）

文件列表勾选框 / Ctrl / Shift 多选文件与目录；单击即切换勾选（无需 Ctrl）+ Shift 范围选择；多选右键仅显示可批量项：批量下载（统一落盘目录、目录递归）、批量删除（逐项递归、汇总结果）（v4.3.3；v4.3.4 修复属性接口；v4.3.7 升级后文件动态命名+桌面快捷方式自动更新）。

ℹ 属性与目录大小计算（v4.3.2）

右键「属性」Windows 资源管理器风格（单选完整属性/多选聚合统计）；右键目录「计算大小」递归统计占用（深度/条目上限防失控，无权限自动跳过），结果直接回填列表（v4.3.3；v4.3.4 修复属性弹窗）。

# 网络与转发

🔀 本地端口转发

127.0.0.1:本地端口 → 目标主机:目标端口，配置随会话持久化，断线重连自动恢复。

🧦 SOCKS 4/5 动态转发（v5.0.13 修复）

本地端口秒变经 SSH 加密隧道的 SOCKS 代理（v2.8.1 起）；修复 v5.0.8 起 dynamic+socks 双字段同现导致启动报 duplicate field `socks` 的问题,已保存转发记录零迁移全部兼容。

# 密钥与安全

🔒 主密码保护

可选启用；密钥经派生函数 + AES-256-GCM 包裹落盘，启动全屏解锁；连续 5 次错误自动锁定。

🧮 派生强化（v4.3.0）

主密码派生迭代 10 万 → 60 万次（OWASP 2023 推荐）；旧数据完全兼容，首次解锁自动透明迁移。

🧬 Argon2id 派生（v4.3.1）

主密码新写入升级 Argon2id（wrap:v3，m=64MiB/t=3/p=1）；v1/v2/v3 三格式兼容可解，旧数据渐进迁移。

🔐 密钥绑定本机（v4.3.1）

config.key 落盘改用 Windows DPAPI 绑定当前用户，配置拷贝到他机不可解密；旧明文密钥自动透明升级，换机时明确提示。

🧱 内容安全策略（v4.3.1）

CSP 收紧至 script-src 'self'，内联脚本外置，远端输出注入防线强化。

💾 配置可靠性（v4.3.0）

config.json 原子写入 + 自动保留最近 5 份滚动备份，断电 / 崩溃不丢配置；密钥文件写入原子化；启动读取失败自动回退备份（v4.3.1）。

🔐 加密存储

会话密码 / 口令以 AES-256-GCM 加密写入 config.json（enc:v1）；启用主密码后无密码不可解。

# 升级与维护

🔐 安全在线升级

检测接口 AES-256-GCM 信封 + HMAC 时效签名（防篡改 / 防重放）；安装包加密流下载，HMAC + SHA-256 双重校验，任一失败不落地安装。

♻ 原地无缝升级

旧 exe 改名 .bak → 新版顶替原名 → 分离启动，快捷方式无缝沿用；任一步被拦截自动回滚旧版；启动自动清理备份残留。

⭐ 桌面/快速启动栏快捷方式（v5.0.9）

设置 → 快捷方式 分组手动一键生成桌面快捷方式与快速启动栏（任务栏固定区）快捷方式，同名覆盖更新、重复点击安全；在线升级完成后两类快捷方式自动同步刷新指向新版文件。

🧹 缓存自愈

版本变更自动清理 WebView2 旧缓存（三重保障：no-store 响应头 + Rust 启动层标记比对 + 应用内清理），升级后运行的永远是全新 UI。

📮 使用反馈

应用内一键提交问题反馈（可附诊断信息），直达开发团队。

📊 匿名使用统计（v5.1.0）

每天首次启动后台上报一次匿名统计（操作系统/CPU/内存磁盘档位/语言/地域），设备标识 SHA-256 去标识化，不含主机名、网卡地址、完整IP等身份信息，仅用于统计不作其他用途；设置 → 升级 → 隐私 可随时关闭。

🛡 官网统一后台管理（v5.1.0）

easyssh.cn/admin.html 统一入口：客户端统计看板（设备数/活跃趋势/版本与硬件分布）与使用反馈管理并入同一登录鉴权；feedback-admin 原地址自动跳转。
