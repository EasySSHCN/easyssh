    安全

    主密码保护: …
    启用后 config.key 会被主密码包裹(config.key.enc):即使 config.json 与密钥文件一起被拷走,没有主密码也解不出已保存的会话密码。首次连接服务器时会弹出指纹确认,防中间人攻击。
    快捷命令管理
      点击工具栏「⚡ 快捷命令」旁的按钮即可发送到当前终端。多行 = 顺序宏(按行依次执行,间隔默认 300ms)。 占位符:{{host}}/{{port}}/{{user}} 自动取当前会话参数;{{input:提示文字}} 执行时弹窗填参(记住上次值)。
      本地端口转发
        连接建立后,访问本机 127.0.0.1:本地端口 的流量将经加密隧道由 SSH 服务器转发到 目标主机:目标端口(可用于安全访问内网数据库/管理台)。会话断开转发自动停止。
