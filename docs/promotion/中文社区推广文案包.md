**标题**:EasySSH:开源的 Windows 绿色版 SSH 终端,免安装、会话随文件夹携带

**正文**:
做了一个开源的 Windows SSH 终端 EasySSH,解决几个自己的痛点:

- **绿色便携**:zip 解压即用,不写注册表、不需要管理员权限,会话配置跟着文件夹走,U 盘/网盘同步目录后到哪台电脑都是熟悉的环境
- **多标签 + SFTP**:左右分栏 SFTP,传输队列、断点续传
- **安全**:会话密码 AES-256-GCM 加密落盘,支持主密码(Argon2id);在线升级 Ed25519 签名校验
- **网络**:端口转发、SOCKS5/HTTP 代理、ProxyJump 跳板(≤3 级)
- **技术栈**:Rust + Tauri 2 + russh + xterm.js,代码 100% 原创(MIT),零闭源组件
