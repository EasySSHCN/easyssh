## 3. 功能规格说明书（M1–M4）

> 每项功能统一格式：**功能描述 → 用户故事 → 交互要点 → 验收标准（Given/When/Then）→ 优先级**。
> 优先级定义：P0 = 里程碑阻塞项，不做完不发版；P1 = 本里程碑应完成，可顺延至下一里程碑；P2 = 增强项，允许裁剪。

### 3.1 M1 地基（目标窗口：4 周）

#### F-M1-01 OTA 升级包 Ed25519 非对称签名

- **功能描述**：升级包由发布机持有的 Ed25519 私钥签名（对安装包字节流 SHA-256 摘要签名，签名随清单下发）；客户端内置公钥（编译期嵌入二进制）验签，验签失败拒绝安装。取代现有"共享对称密钥 + HMAC"的单一防线，消除"客户端即密钥持有者"的伪造风险。
- **用户故事**：
  - 作为安全敏感的用户，我希望升级包经过非对称签名验证，以便即使官方服务器被入侵、我也不会安装未经发布机私钥签名的恶意包。
  - 作为发布工程师，我希望私钥只存在于发布机，以便开发机失窃也无法伪造升级包。
- **交互要点**：
  - 验签失败时横幅显示"升级包签名校验失败，已中止安装"，并提供官网手动下载链接与该包 SHA-256 供人工比对。
  - 设置页「检查更新」详情区展示当前升级通道的签名公钥指纹（前 16 位）。
- **验收标准**：
  - Given 一份官方发布机签名的升级包，When 客户端下载并执行验签，Then 验签通过且允许进入替换流程。
  - Given 篡改任意 1 字节后的升级包，When 验签，Then 拒绝安装并在横幅展示失败原因，`updates/` 目录不落地可执行文件。
  - Given 伪造清单（签名字段替换为攻击者自签），When 验签，Then 拒绝并记录安全事件日志（升级日志文件）。
  - Given 客户端二进制，When 提取内嵌公钥指纹，Then 与官网公示指纹一致。
- **优先级**：P0

#### F-M1-02 升级自回滚（健康自检失败自动回滚）

- **功能描述**：升级后新版以 `--upgraded` 启动时执行健康自检（窗口创建成功、前端首帧渲染、核心命令 ping 通、配置读写正常），自检通过后删除 `.bak`；失败则以 `.bak` 旧版回滚启动并提示用户。延续 v4 的"旧 exe 改名 .bak → 新版顶替 → 分离启动 --upgraded"机制，补齐"新版坏了自动回老版"闭环。
- **用户故事**：作为普通用户，我希望升级后如果新版无法正常启动，软件能自动回滚到旧版本，以便我的工作不因一次失败的升级而中断。
- **交互要点**：回滚发生时启动画面显示"新版健康检查未通过，已自动恢复旧版本 vX.Y.Z"；设置页提供「上报本次回滚」（匿名，含版本对与失败阶段）。
- **验收标准**：
  - Given 新版正常启动且自检全部通过，When 自检完成，Then `.bak` 在 60s 内被删除。
  - Given 人为构造前端初始化失败的新版（测试专用故障注入开关），When 以 `--upgraded` 启动，Then 30s 内回滚启动 `.bak` 旧版，且用户可见回滚提示。
  - Given 回滚执行中旧 exe 被占用，When 重试 3 次仍失败，Then 保留 `.bak` 并在下次启动时重试清理，绝不删除用户唯一可用的程序文件。
- **优先级**：P0

#### F-M1-03 Argon2id 默认密钥派生

- **功能描述**：主密码派生从 PBKDF2-SHA256 600k（wrap:v3）升级为 Argon2id（m=64MiB, t=3, p=1，wrap:v4）作为新写入默认；v1/v2/v3 全兼容可解，首次解锁后透明迁移。v4.3.1 已引入 Argon2id，本项将其定为唯一默认并补齐强制迁移与降级防护。
- **用户故事**：作为启用主密码的用户，我希望我的口令使用抗 GPU 暴力破解的现代算法派生密钥，以便配置文件被拷走时口令难以被离线破解。
- **交互要点**：无感知；设置页主密码卡片显示当前"加密格式：Argon2id (wrap:v4)"。
- **验收标准**：
  - Given 全新启用主密码，When 查看 config.key.enc 头部，Then 标记为 wrap:v4。
  - Given wrap:v1/v2/v3 旧文件，When 解锁，Then 解密成功且解锁成功后自动重写为 v4。
  - Given Argon2id 派生单次耗时，When 在参考机型（4 核/8GB）实测，Then 200ms–1000ms 区间内。
- **优先级**：P0

#### F-M1-04 renderer.js 模块化拆分起步

- **功能描述**：将 ui/renderer.js（约 2081 行单体）按职责拆分为 ES Module：`core/`（config、i18n、event-bus）、`tabs/`、`term/`、`sftp/`、`forward/`、`settings/`、`update/`，经 Vite 构建输出单入口 bundle；零框架策略不变。M1 仅完成骨架与 2–3 个模块的物理拆分（sftp、update、settings），后续里程碑持续迁出。
- **用户故事**：作为开发者，我希望前端代码模块化，以便多人协作时不冲突、缺陷定位可按模块归因。
- **交互要点**：无用户可见变化（行为完全等价）。
- **验收标准**：
  - Given 拆分后构建产物，When 运行回归用例（连接/传文件/升级检查/设置切换共 20 条冒烟），Then 全部通过且无行为差异。
  - Given renderer.js，When M1 结束，Then 主文件 ≤ 600 行，新增模块均有单文件职责边界注释与导出清单。
  - Given 构建管线，When `pnpm build`，Then 产出带内容哈希文件名的 bundle 且 CSP `script-src 'self'` 保持有效。
- **优先级**：P0

### 3.2 M2 效率健壮（目标窗口：5 周）

#### F-M2-01 SFTP 传输管道化

- **功能描述**：大文件读写请求流水线化：并发在途请求 8–16（可配）、调大 russh-sftp 窗口（建议 2MB read window / 256KB packet）、可选 zstd 压缩（默认关，仅压缩收益大的文本类内容推荐开启）。
- **用户故事**：作为运维工程师，我希望千兆内网传大文件能跑满带宽，以便镜像/备份任务从小时级降到分钟级。
- **交互要点**：设置 → 传输：并发深度（4/8/16）、zstd 开关；传输队列详情显示当前在途请求数与实时速率曲线。
- **验收标准**：
  - Given 千兆局域网 + 本地 NVMe 服务器，When 下载 1GB 单文件，Then 平均吞吐 ≥ 100MB/s（v4 基线 ≥ 3 倍）。
  - Given 高延迟链路（模拟 100ms RTT），When 相同文件，Then 吞吐相对串行基线提升 ≥ 3 倍。
  - Given zstd 开启且传输文本日志类文件，When 完成后比对源与目标 SHA-256，Then 完全一致（压缩不损正确性）；二进制文件自动禁用压缩。
- **优先级**：P0

#### F-M2-02 SFTP 断点续传（上传 + 下载全量）

- **用户故事**：作为用户，我希望 10GB 文件传输中途断线后重连能从断点继续，以便不必前功尽弃。
- **交互要点**：传输队列中断任务显示「▶ 续传」与已传百分比；续传前校验远端文件大小 ≥ 本地 offset，不满足则提示"远端文件已变化，建议重传"。
- **验收标准**：
  - Given 500MB 下载在 40% 时断网，When 网络恢复点「续传」，Then 从 ~200MB 处继续且最终文件 SHA-256 与源一致。
  - Given 上传中断后续传，When 远端已有部分文件，Then 以 append 方式续写且结果校验一致。
  - Given 续传时远端文件 mtime 变化，When 点击续传，Then 弹出警告且默认不自动续传。
- **优先级**：P0（下载已有单文件基础，补齐上传与队列级状态持久化）

#### F-M2-03 断线会话状态恢复

- **功能描述**：意外断线自动重连成功后，恢复会话现场：工作目录 cwd（连接后自动 `cd` 回原目录）、导出的环境变量、以及 scrollback 缓冲回放（本地缓冲重灌，非服务器侧）。
- **用户故事**：作为运维工程师，我希望断线重连后终端还在原来的目录、还能看到之前的输出，以便不用重敲命令和翻找日志。
- **交互要点**：重连横幅提示"已恢复会话现场（目录：/var/log）"；设置开关「断线恢复现场」默认开。
- **验收标准**：
  - Given 会话内 `cd /var/log && export FOO=bar`，When 断线自动重连成功，Then 提示符所在目录为 /var/log 且 `echo $FOO` 输出 bar。
  - Given 断线前 scrollback 有 3000 行，When 重连完成，Then 缓冲保留且可回滚查看。
  - Given 主动关闭的会话，When 重开，Then 不恢复旧现场（新会话从 HOME 开始）。
- **优先级**：P0

#### F-M2-04 WebGL 终端渲染

- **功能描述**：接入 `@xterm/addon-webgl`，GPU 渲染终端；WebGL 不可用（远程桌面/老驱动）自动回退 DOM 渲染并记录。
- **用户故事**：作为开发人员，我希望 `cat` 大文件、跑构建日志时终端滚动丝滑不掉帧，以便高强度输出时不卡顿。
- **交互要点**：设置 → 终端：渲染器（自动/WebGL/DOM）。
- **验收标准**：
  - Given 支持 WebGL2 的机器，When 打开会话，Then DevTools 确认 WebGL 渲染器激活。
  - Given `seq 1 100000` 输出，When 记录渲染帧率，Then 平均帧间隔 ≤ 20ms 且 UI 线程无 >100ms 长任务。
  - Given WebGL 初始化失败，When 回退，Then 终端功能完全可用且设置页显示"已回退 DOM 渲染"。
- **优先级**：P1

#### F-M2-05 SOCKS5/HTTP 代理 + ProxyJump 跳板机

- **功能描述**：会话连接支持前置代理（SOCKS5 / HTTP CONNECT，可选认证）；支持 ProxyJump 跳板链（复用端口转发基础设施），UI 可视化编辑 `A → B → C` 链路。
- **用户故事**：作为运维工程师，我希望配置"公司代理 → 跳板机 → 目标内网机"的链路后一键连接，以便不再手工逐级 ssh。
- **交互要点**：连接表单新增「网络」折叠区：代理类型/地址/端口/凭据；跳板链编辑器支持拖拽排序、链路连通性测试按钮（逐级握手并显示各级耗时）。
- **验收标准**：
  - Given SOCKS5 代理（含用户名密码）配置，When 连接目标机，Then TCP 经代理建立且会话正常登录。
  - Given 两级跳板链 A→B→C，When 连接 C，Then 握手成功且 C 上 `who` 来源 IP 为 B。
  - Given 链路测试按钮，When 中间节点不可达，Then 明确提示"第 2 级 B 连接失败：<原因>"。
  - Given HTTP CONNECT 代理拒绝 CONNECT 方法，When 连接，Then 报错信息区分"代理拒绝"与"目标不可达"。
- **优先级**：P0

#### F-M2-06 panic hook 崩溃日志

- **用户故事**：作为用户，我希望软件崩溃后官方能拿到可定位的日志，以便快速修复；作为开发者，我希望 Rust panic 时记录堆栈而非静默闪退。
- **交互要点**：崩溃后下次启动提示"上次异常退出，是否上报匿名崩溃日志"（含版本/panic 位置/堆栈摘要，不含用户数据）。
- **验收标准**：
  - Given 测试注入 panic，When 触发，Then `logs/crash/` 生成含时间戳、版本、线程、堆栈的日志文件。
  - Given 下次启动检测到未上报崩溃日志，When 用户同意上报，Then 走加密反馈通道提交且日志本地归档；拒绝则仅本地保留。
- **优先级**：P0

#### F-M2-07 russh 集成测试地基 + 发版冒烟门禁

- **功能描述**：搭建本地 sshd 容器化集成测试环境（密码/密钥/keyboard-interactive/端口转发/SFTP 全链路），纳入 CI；发版前强制执行冒烟门禁（版本校验 → 启动 exe → OTA 端到端自测）。
- **用户故事**：作为开发者，我希望每次改动都有 SSH 协议层回归测试兜底，以便升级 russh 或改动连接层时不再靠手工连真机验证。
- **验收标准**：
  - Given CI 环境，When 运行集成测试套件，Then 覆盖 ≥ 15 条用例（认证 3 种、转发 2 种、SFTP 8 项操作、会话事件）且全绿 ≤ 10 分钟。
  - Given 发版流水线，When 冒烟门禁任一步失败，Then 流水线终止且禁止发布。
- **优先级**：P0（门禁）/ P1（测试覆盖扩充）

### 3.3 M3 UI 设计系统（目标窗口：4 周）

#### F-M3-01 Design Tokens（深浅主题）

- **功能描述**：建立 `tokens.json`（颜色/圆角/间距/字号/阴影两级变量），深浅双主题 + 5 款既有皮肤全部迁移为 token 派生；CSS 自定义属性消费，运行时可切换。
- **用户故事**：作为开发者，我希望所有颜色/间距来自统一 token，以便新增界面自动符合主题且深浅切换零遗漏。
- **验收标准**：
  - Given 全量界面遍历检查清单（≥ 30 个页面/弹窗），When 深浅切换，Then 无硬编码颜色残留（lint 脚本扫描 CSS 中 `#[0-9a-f]{3,8}` 裸值为 0）。
  - Given 新增 token，When 构建校验，Then 未被消费或未声明的 token 报 warning。
- **优先级**：P0

#### F-M3-02 内置 SVG 图标集

- **功能描述**：替换现有 emoji/字符图标（⇅ ✎ ▶ 等），内置 ~60 个 SVG 图标（单色 currentColor），按语义命名（`icon-connect.svg` 等），构建期 sprite 内联。
- **用户故事**：作为用户，我希望图标在任何 DPI 下都清晰、随主题变色，以便界面精致专业。
- **验收标准**：
  - Given 200% 缩放，When 检查工具栏/侧栏/菜单，Then 无位图/emoji 图标残留。
  - Given 图标清单，When 构建校验，Then 每个被引用图标存在且无未引用孤儿（孤儿移除）。
- **优先级**：P1

#### F-M3-03 设置页卡片式重设计

- **功能描述**：设置从长列表改为分组卡片（账户安全/终端/传输/网络/外观/升级/关于），每卡片含标题、说明、控件与恢复默认；支持搜索定位设置项。
- **用户故事**：作为轻度用户，我希望设置项按场景分组且可搜索，以便快速找到"改字体"这类低频设置。
- **验收标准**：
  - Given 设置搜索框输入"字体"，When 回车，Then 定位到终端外观卡片并高亮该控件。
  - Given 迁移核对表（v4 全部设置项 ≥ 120 项），When 对照，Then v5 无设置项丢失且默认值不变。
- **优先级**：P0

#### F-M3-04 终端字体连字与主题联动

- **功能描述**：接入 `@xterm/addon-ligatures`（可选开关，默认开，需安装等宽连字字体才生效）；终端配色完全由当前主题 token 派生，切主题即时生效。
- **验收标准**：
  - Given 安装了 Cascadia Code 且连字开启，When 输入 `=>` `!=`，Then 渲染为连字字形。
  - Given 切换深→浅主题，When 已打开 5 个终端标签，Then 5 个标签配色全部即时更新（无需重连）。
- **优先级**：P1

#### F-M3-05 动效规范

- **功能描述**：定义动效 token（时长 120/200/300ms、缓动曲线、适用场景清单：弹窗进出/标签切换/传输进度/横幅）；全部动效尊重 `prefers-reduced-motion`。
- **验收标准**：
  - Given 系统开启"减少动态效果"，When 操作界面，Then 非必要动效全部禁用（代码审查 + 录屏核对）。
  - Given 弹窗开关操作，When 主线程采样，Then 无 >16ms 的动画帧（CSS transform/opacity only，不触发布局）。
- **优先级**：P2

### 3.4 M4 功能增强（目标窗口：6 周）

#### F-M4-01 终端分屏（2/4 屏）

- **功能描述**：单标签页内水平/垂直分屏（2 屏、4 屏布局），每格独立会话或同会话只读镜像；支持拖拽调整分隔条。
- **用户故事**：作为运维工程师，我希望一个窗口里同时看 `top`、日志 tail 和操作台，以便排查问题时不必切标签。
- **交互要点**：标签工具栏「分屏」下拉（左右/上下/四宫格/恢复单屏）；焦点格高亮边框；快捷键 Ctrl+Alt+方向键切换焦点。
- **验收标准**：
  - Given 四宫格分屏，When 在每格各开一个会话，Then 4 会话独立输出互不串扰。
  - Given 2 屏选择"同会话镜像"，When 左格输入命令，Then 两格输出同步且右格输入被锁定（只读）。
  - Given 拖动分隔条，When 释放，Then 布局比例持久化到下次打开。
  - Given 3 个分屏中 1 个会话断开，When 断开，Then 该格显示重连提示且其余格不受影响。
- **优先级**：P0

#### F-M4-02 SFTP 传输队列（暂停/恢复/优先级）

- **功能描述**：在 v4 传输队列之上增加：单任务暂停/恢复、任务优先级调整（置顶/上移/下移）、全局并发与单任务限速。
- **用户故事**：作为用户，我希望大文件传输可以暂停给即时操作让路、紧急小文件可以插队，以便灵活管理带宽。
- **验收标准**：
  - Given 进行中的 1GB 下载，When 点暂停，Then 速率归零且进度冻结；点恢复，Then 从暂停处继续且最终校验一致。
  - Given 队列 5 个任务，When 将第 5 个置顶，Then 下一开始传输的就是它。
  - Given 限速 10MB/s，When 传输 100MB，Then 实测平均速率 9–11MB/s。
- **优先级**：P0

#### F-M4-03 SFTP 同步浏览（双栏）

- **功能描述**：本地↔远程双栏视图，联动目录导航（可选开关）、双栏间拖拽传输。
- **用户故事**：作为开发人员，我希望像资源管理器一样左右两栏对照拖文件，以便直观完成上传下载。
- **验收标准**：
  - Given 同步浏览开启，When 左栏进入 D:\proj\src，Then 右栏自动跟随进入会话配置的映射目录。
  - Given 左栏选中 3 个文件拖到右栏，When 释放，Then 入队上传且进度在队列面板可见。
  - Given 关闭同步，When 左栏切换目录，Then 右栏保持不动。
- **优先级**：P1

#### F-M4-04 脚本库升级（变量占位符 + 顺序宏）

- **功能描述**：快捷命令升级为脚本库：支持 `{{变量名}}` 占位符（发送前弹窗填参，记住上次值）、多条命令顺序宏（可设间隔毫秒）、全局/会话两级作用域。
- **用户故事**：作为运维工程师，我希望一键执行"cd {{目录}} && tail -n {{行数}} {{日志文件}}"，以便常用排查流程参数化复用。
- **验收标准**：
  - Given 含 2 个变量的宏，When 点击执行，Then 弹窗收集参数（默认填上次值）并按序发送，间隔符合配置（±50ms）。
  - Given 会话级脚本与全局同名，When 该会话执行，Then 优先会话级。
  - Given 导出脚本库 JSON，When 另一台机器导入，Then 变量与宏结构完整（密码类变量标记为敏感、导出剔除）。
- **优先级**：P0

#### F-M4-05 全局命令面板（Ctrl+Shift+P）

- **功能描述**：类 VS Code 命令面板：模糊搜索全部动作（连接会话/切换主题/打开设置/执行脚本/端口转发…），键盘全操作。
- **用户故事**：作为熟练用户，我希望不碰鼠标完成一切高频操作，以便效率最大化。
- **验收标准**：
  - Given 面板打开，When 输入 "web" 且存在会话 web-prod，Then 模糊匹配置顶并可 Enter 直连。
  - Given 面板，When 列出动作清单，Then 覆盖 ≥ 40 个注册动作且每项含所属分组标签。
  - Given 中文输入"连接"，When 搜索，Then 命中含"连接"语义的动作（动作注册含中文别名）。
- **优先级**：P1

#### F-M4-06 会话录制回放

- **功能描述**：基于 asciicast v2 格式录制会话输出与时间戳（可含输入，默认只录输出），支持回放（倍速）、导出 .cast、录制文件脱敏检查提示。
- **用户故事**：作为安全敏感团队管理员，我希望值班操作可录制回放，以便事后审计关键变更过程。
- **验收标准**：
  - Given 开启录制的会话，When 执行命令产生输出 10 分钟，Then 生成 .cast 且 asciinema 官方播放器可正常回放。
  - Given 回放，When 选择 2x/4x 倍速，Then 时间轴按倍速压缩且顺序正确。
  - Given 录制含 `password` 字样输出行，When 停止录制，Then 弹出脱敏提示（用户可选择遮蔽该行再保存）。
- **优先级**：P1

#### F-M4-07 端口转发规则持久化增强

- **功能描述**：端口转发规则升级为独立规则库（跨会话复用/全局启用/按会话绑定），支持导入导出、规则启用即验证端口占用。
- **用户故事**：作为运维工程师，我希望常用转发规则只定义一次、任意会话一键套用，以便不再逐会话重复配置。
- **验收标准**：
  - Given 全局规则"3306→db-prod"，When 在 3 个不同会话启用，Then 3 会话各自建立转发且互不冲突（同本地端口时第二个启用被拦截并提示）。
  - Given 导出规则库，When 导入，Then 主机/端口/类型字段无损；密码类字段不存在于导出文件。
  - Given 规则启用时本地端口被占用，When 点击启用，Then 即时报错并给出占用进程名。
- **优先级**：P1

### 3.5 安全专项（贯穿 M1–M3）

#### F-S-01 known_hosts 主机密钥管理界面

- **功能描述**：图形化管理已信任主机密钥：列表（主机/端口/算法/SHA256 指纹/首次信任时间）、删除、批量导出 OpenSSH known_hosts 格式；连接时主机密钥变更（rotation）分级告警（同算法换 key=高危 MITM 告警；新增算法 key=提示确认）。
- **用户故事**：作为安全敏感用户，我希望集中查看和审计我信任过的所有主机指纹，以便发现异常信任记录并一键清除。
- **验收标准**：
  - Given 10 条信任记录，When 打开管理界面，Then 每条显示主机/算法/指纹/信任时间且支持单条删除（删除后下次连接重新 TOFU 确认）。
  - Given 服务器主机密钥更换，When 重连，Then 弹高危告警（默认拒绝），明确展示新旧指纹并需显式确认才更新。
  - Given 导出，When 生成 known_hosts，Then `ssh` 可直接使用该文件连接同一主机。
- **优先级**：P0

#### F-S-02 FIDO2 硬件密钥（ed25519-sk）

- **功能描述**：支持生成与使用 `ed25519-sk` 硬件密钥认证（触摸确认），密钥生成界面新增"硬件密钥"选项；依赖服务器端 OpenSSH ≥ 8.2。
- **用户故事**：作为安全敏感用户，我希望私钥永远不离开我的硬件令牌，以便私钥文件泄露也无法被用于登录。
- **验收标准**：
  - Given 已接入 FIDO2 设备，When 生成 ed25519-sk 密钥，Then 生成需触摸确认且私钥句柄存于本机 keys/ 目录。
  - Given 使用 sk 密钥连接支持的服务器，When 认证，Then 提示触摸并在确认后登录成功。
  - Given 不支持 sk 的服务器，When 认证，Then 明确报错"服务器不支持 sk 密钥（需 OpenSSH ≥ 8.2）"。
- **优先级**：P1（Windows FIDO2 中间层适配风险高，允许降级为实验特性开关）

#### F-S-03 OpenSSH config 导入

- **功能描述**：解析 `~/.ssh/config`（Host/HostName/User/Port/IdentityFile/ProxyJump/ProxyCommand 子集），生成 EasySSH 会话（ProxyCommand 不支持项标注跳过清单）。
- **用户故事**：作为开发人员，我希望已有 ssh config 一键导入，以便无缝切换到 EasySSH。
- **验收标准**：
  - Given 含 20 个 Host 的 config（含 2 个 ProxyJump、1 个 ProxyCommand），When 导入，Then 生成 20 会话，ProxyJump 转为跳板链，ProxyCommand 项出现在跳过清单。
  - Given 含通配符 Host（`Host *`），When 导入，Then 通配段作为默认值合并而非生成无效会话。
  - Given IdentityFile 指向不存在文件，When 导入，Then 该会话标记警告"私钥文件缺失"。
- **优先级**：P1

#### F-S-04 cargo audit 进构建

- **功能描述**：CI 增加 `cargo audit`（RustSec advisory 库扫描）步骤；发现高危漏洞 CVE 时构建失败（允许白名单豁免 + 豁免到期日强制复审）。
- **验收标准**：
  - Given 依赖树含已知高危 RUSTSEC 告警，When CI 运行，Then 构建失败并输出告警详情与修复建议。
  - Given 豁免条目，When 超过豁免到期日，Then 构建重新失败强制复审。
- **优先级**：P0

#### F-S-05 弱密码检测 + 密码生成器

- **功能描述**：新建/编辑会话保存密码时执行弱密码检测（长度 <8、纯数字、键盘序列、常见字典 TOP1000），命中给非阻断警告；连接与表单内提供密码生成器（长度/字符集可配）。
- **用户故事**：作为轻度用户，我希望设置弱密码时被提醒、需要强密码时一键生成，以便降低服务器被爆破的风险。
- **验收标准**：
  - Given 密码 "123456"，When 保存会话，Then 显示黄色警告（可继续保存）。
  - Given 生成器默认配置（16 位，含大小写数字符号），When 生成，Then 每次结果满足字符集且长度精确。
  - Given 密码强度评估，When 本地执行，Then 不产生任何网络请求（纯本地实现）。
- **优先级**：P1
