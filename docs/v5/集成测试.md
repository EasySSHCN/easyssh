# 集成测试指南（v5(M2)/F-M2-07 测试地基）

## 测试布局

| 文件 | 内容 | CI |
|------|------|----|
| `src-tauri/tests/update_guard_tests.rs` | 升级自回滚看护/回滚纯逻辑（≥5 条，M1 遗留闭环） | 默认执行 |
| `src-tauri/tests/ssh_integration_tests.rs` | russh 协议层真实连接（骨架 + echo ok 示例） | `#[ignore]`，手动运行 |
| `src-tauri/tests/xfer_pipeline_tests.rs` | 传输管道/代理跳板/续传纯逻辑（16 条，v5 beta 任务二扩充） | 默认执行 |

说明：`easyssh` 是 binary crate（无 lib.rs），`update_guard_tests` 以 `#[path = "../src/update_guard.rs"]` 把该模块（仅依赖 std）直接编入测试 crate，不改动 crate 结构。
`xfer_pipeline_tests` 同理编入 `src/xfer_core.rs`（std + serde_json 纯逻辑：范围切分/续传/journal/优先级/暂停状态机/限速/SOCKS5 与 HTTP CONNECT 编解码/跳板链展开），xfer.rs 与 net.rs 运行时复用同一实现，行为不变。

## 升级自回滚测试（CI 跑）

```
cargo test -p easyssh --test update_guard_tests
```

覆盖：健康及时→不回滚；超时未标记→回滚计划正确；无 .bak→不删唯一可用文件；.failed 防重入；回滚改名后 exe/.bak/.failed 终态断言；改名失败恢复原状；路径推导回归。

### 进程操作类手动验证

`update_guard` 的 `launch()`/`process::exit()` 会终止测试进程自身，无法在 cargo test 内直接调用；完整链路（`--upgraded` 超时→真实回滚→`--rollback` 启动）依赖双版本 exe 与 GUI 环境，按手册 S-OTA-04 以**真实发版演练**人工验收：

1. 构建新旧两个版本 exe，用 `update_complete` 升级路径或手工摆放 `.bak`；
2. 以 `EasySSH-<新版>-portable.exe --upgraded <新版>` 启动，15 秒内不创建主窗口（或等 15s）→ 观察自动回滚：exe 改名 `.failed`、`.bak` 恢复原主文件名、旧版以 `--rollback` 分离启动；
3. `t90_manual_real_process_spawn_and_exit`（`#[ignore]`）验证测试环境进程原语：

```
cargo test -p easyssh --test update_guard_tests -- --ignored
```

## russh 集成测试（本机 sshd）

### 启用本机 OpenSSH Server（Windows）

```powershell
# 管理员 PowerShell
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service -Name sshd -StartupType Automatic
# 测试账号用本机用户名+密码（或新建专用账号）
```

### 运行

```powershell
$env:EASYSSH_TEST_SSH = '127.0.0.1:22/<用户>/<密码>'
cargo test -p easyssh --test ssh_integration_tests -- --ignored
```

- 未设置 `EASYSSH_TEST_SSH` 时真实连接用例自动跳过（`#[ignore]` + 运行期双保险），CI 无环境不报错。
- 现有示例：连接 → 密码认证 → `channel.exec("echo ok")` → 断言输出 `ok`。

## 穷尽不了的场景与后续扩展点

手册 F-M2-07 验收要求 ≥15 条（认证 3 种 / 转发 2 种 / SFTP 8 项 / 会话事件），当前为地基骨架，扩展点已在 `ssh_integration_tests.rs` 末尾注释列出：

1. **认证矩阵**：公钥、keyboard-interactive、错误密码负路径；
2. **端口转发**：local forward / reverse forward（sshd 需 AllowTcpForwarding yes）；
3. **SFTP 8 项操作**：open/list/mkdir/rename/remove/remove_dir/metadata/读写回环（需可写测试目录）；
4. **会话事件**：多通道并发、通道关闭、resize 后输出；
5. **容器化**：W5 规划为本地 sshd 容器（如 linuxserver/openssh-server），只需把 `EASYSSH_TEST_SSH` 指向容器端口即可复用本骨架，无需改测试代码；
6. **OTA 端到端**：签名清单 → 真实替换 → 自回滚全链路在 CI 自动化（当前依赖 GUI，人工演练）。
