# v5(M4) 传输队列增强与端口转发持久化（后端）说明

对应手册 F-M4-02（暂停/恢复/优先级，P0）与 F-M4-07（转发规则持久化，P1）。
前端 UI 接线属前端代理范围，本文仅描述后端行为与命令契约。

## 一、传输队列暂停/恢复（F-M4-02 P0）

- 实现：`src-tauri/src/xfer.rs`
- 暂停状态机：worker 每传完一个块做门控决策 `worker_gate(paused, cancelled)`：
  - 取消优先于暂停：取消 → 立即终止（返回「已取消」）；
  - 暂停 → `WaitPaused`：**在途块写完后停等**（60ms 轮询旗标），不发起新块请求；
  - 否则推进下一块。
- 断点语义：
  - 暂停=任务保活：断点在各 worker 内存计数里，恢复后原地继续，**不需要**重走 resume journal；
  - 取消/失败=任务终止：断点照旧写入 `xfer-resume.json`（与 M2 一致，前端 ▶续传可用）；
  - 简单暂停→取消→续传链路因此全部兼容。
- 事件：`xfer:progress` 新增 `status/phase = "paused"` 段（暂停期间 ticker 推 paused 且速率归零）；
  其余字段（id/taskId/received/total/bytesDone/bytesTotal/speedBps）不变，前端向后兼容。
- 命令：
  - `xfer_pause(task_id)` → `{ok, status:"paused"}`；任务不存在/已结束时报错
  - `xfer_resume(task_id)` → `{ok, status:"running"}`；未暂停时报错

## 二、传输优先级（F-M4-02 P1）

- 任务带 `priority`（`high`/`normal`/`low`，缺省 normal；未知值按 normal）。
- 旧 Semaphore 闸门升级为**优先级调度器**（单实例，首次 `xfer_start` 惰性拉起）：
  - 全局并发槽位 = capacity（默认 4，与 v4.3.1 一致）；
  - 入队事件 `(rank, id)` 由 `pick_next` 选路：rank 小者优先，同 rank 按 id（=入队顺序）；
  - 任务结束 `Finished` 归还槽位，调度器立即补位下一个最高优先任务。
- 排队中的任务可被取消（不占槽位，直接 cancelled，不误发 Finished）。
- 事件：任务记录与 `xfer:progress` 均带 `priority` 字段（前端 UI 展示用）。
- 命令：`xfer_start` 新增可选参数 `priority: "high"|"normal"|"low"`。

## 三、端口转发规则持久化（F-M4-07 P1 后端部分）

- 会话记录新增一级字段 `forwards`（与 `proxy`/`jumpChain` 同模式）：
  数组元素即 `pf_start` 的 cfg（`name`/`localPort`/`remoteHost`/`remotePort`/`socks`）。
  旧会话无该字段 = 无规则，零迁移。
- 会话键与渲染端 forward.js 一致：`host:port:username`（port 缺省 22）。
- 命令：
  - `pf_forwards_save(sessionKey, forwards)` → 覆盖式保存（config.json 加密落盘）
  - `pf_forwards_get(sessionKey)` → `Vec<rule>`（无规则返回空数组）
  - `pf_apply_session(id, sessionKey)` → 一键批量应用：逐条 `pf_start`；
    返回 `{ok, started, skipped, errors:[{localPort,error}]}`；
    「已在监听本地端口 N」的重复规则计 skipped 不算错。
- 密码类字段不属于转发规则结构，天然不入库。

## 四、测试

`cargo test --workspace` 全绿。xfer.rs 新增单测：
- `worker_gate_pause_state_machine`：暂停状态机（取消>暂停>推进）+ 优先级 rank 排序
- `pause_flag_transitions_preserve_breakpoint`：暂停/恢复旗标翻转不触碰断点，断点 roundtrip 只前进不回退
- `scheduler_priority_ordering`：调度器选路（高优先先、同优先 FIFO、空队列）

## 五、遗留

- 手册 F-M4-02 的「单任务限速」「置顶/上移/下移」（队列内重排）未在本批实现；
  当前优先级在入队时确定，运行中改优先级需后续支持（调整 starts 队列 rank）。
- F-M4-07 的「独立规则库（跨会话复用/导入导出/占用进程名提示）」属后续增强；
  本批只做会话级 forwards 持久化 + 批量应用。
- 取消语义说明：M2 起取消的任务保留断点可续传（F-M2-02 验收要求，前端 ▶续传依赖），
  与「暂停=断点保留」的区别在于任务是否保活（取消后任务终结、需重建，暂停中任务原地继续）。
