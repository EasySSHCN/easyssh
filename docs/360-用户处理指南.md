# 360 安全卫士误报处理操作指南（EasySSH v4 用户）

## 现象
下载/运行 EasySSH 新版本时，360 弹出「有风险程序正准备运行」或「包含木马病毒已隔离」
（判名 Trojan.Win64.SilverFox）。经核查为**误报**（EasySSH 为 MIT 开源 SSH 管理工具，
已向 360 官方提交申诉，处理中）。

## 立即可用的解决步骤

### 方法一：找回被隔离的文件（推荐）
1. 打开 360 安全卫士 → 「木马查杀」
2. 点右下角「**恢复区**」（或「信任区」→「恢复隔离文件」）
3. 勾选列表中的 `EasySSH.exe` / `EasySSH-4.x.x-portable.exe`
4. 点「**恢复并信任**」——之后该文件不会再被拦截
5. 重新运行 EasySSH

### 方法二：添加信任目录（一劳永逸）
1. 打开 360 安全卫士 → 「木马查杀」→ 右下角「**信任区**」
2. 点「添加目录」→ 选择 EasySSH 安装目录（如 `P:\Program Files (x86)\EasySSH`）
3. 确定后重新解压/运行下载的 EasySSH 文件

### 方法三：临时退出 360 完成解压/安装
1. 右键任务栏 360 图标 → 「退出」→ 确定
2. 解压 zip / 运行安装程序
3. 重新开启 360（首次运行 EasySSH 时若弹窗，选择「允许运行」并勾选「不再提醒」）

## 说明
- EasySSH 是 MIT 开源软件，源码公开（github.com/EasySSHCN/easyssh），无任何恶意行为
- 官网提供全部文件的 SHA256 校验值，可与下载文件比对
- 误报申诉已提交 360 官方（opensoft@360.cn），处理中
- 若使用其它安全软件（火绒/腾讯管家等）遇到同样提示，操作类似（信任区/白名单）
