# EasySSH v4 更新日志

## v4.3.0 (2026-11-02) — 安全加固 · 健壮性加强 · 执行效率提升

### 安全加固
- **主密码派生强化（wrap:v2）**：PBKDF2-SHA256 迭代次数 100,000 → **600,000**（OWASP 2023 推荐），显著提升离线暴力破解成本。旧 `wrap:v1` 数据完全兼容可解，**首次解锁成功后自动透明迁移**到 v2（无需用户操作）。
- **密钥文件写入原子化**：`config.key` / `config.key.enc` 生成与改写统一走 tmp→fsync→rename，杜绝断电/崩溃留下残缺密钥文件导致配置锁死。

### 健壮性加强
- **config.json 原子写入 + 滚动备份**：保存改为 `config.json.tmp → fsync → rename`，杜绝半写损坏；每次保存自动滚动备份 `config.json.bak.1~5`（保留最近 5 份），配置损坏时可手动回退。
- **release 构建 panic 策略 abort → unwind**：任何 Rust panic 不再直接闪退（会话/传输全丢），允许上层捕获记录；代价约 +1~2MB 包体。

### 执行效率提升
- **终端输出 16ms 合帧批量推送**：高频输出（cat 大文件 / top）由逐包 IPC 改为聚合缓冲，16ms 定时或 64KB 阈值统一推送，大幅降低 IPC 次数与 CPU 占用；通道关闭前冲刷残留输出，末尾数据不丢。
- **传输进度事件节流**：SFTP 传输进度由每 256KB 一次改为 100ms 或 ≥1% 增量推送，大文件传输不再形成事件风暴；完成/失败/取消状态必达。

### 兼容性
- 3.x / 4.x 配置目录布局与 `config.json` / `config.key(.enc)` 格式不变；升级即用，旧主密码首次输入后自动升级为 v2 加密。
- `enc:v1` 秘密字段格式不变。

### 已知事项
- 密钥未迁移提示：启用主密码的旧用户第一次解锁时约多耗 0.3~0.5 秒（600k 迭代派生），属预期安全开销。
