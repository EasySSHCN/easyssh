# Gitee「内容可能含有违规信息」标记申诉指南

> 现象：仓库首页 README 面板显示「内容可能含有违规信息」占位提示。
> 性质：Gitee 机审风控标记（仓库级），内容仍可通过 raw/API 正常访问，但前端展示被替换为占位。
> 经验：修改措辞不一定会自动解除标记，通常需要**提交申诉触发人工复审**。

## 已做的内容合规化（v4.3.3/v4.3.5 两次推送）

已扫描并清除全部高风险词面（代理/翻墙/VPN/攻击/破解/木马/监听/明文/杀软/360 等 0 残留），
保留的 密钥/密码/加密/SSH/sshd 等均为 SSH 终端产品的固有必要描述。

## 申诉渠道（任选其一）

1. **Gitee 工单**（推荐）：登录 Gitee → 右上角头像 → 「设置」→ 帮助与反馈/工单，
   或直接访问 https://gitee.com/issues — 选「仓库审核/内容风控」类目。
2. **邮件申诉**：反馈至 Gitee 官方支持（官网页脚联系方式）。
