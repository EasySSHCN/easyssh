360 安全卫士误报处理指引

下载或运行 EasySSH 时被 360 提示/隔离（判名 Trojan.Win64.SilverFox）为误报。EasySSH 是 MIT 开源 SSH 管理工具，误报申诉已提交 360 官方处理中。按以下任一方法即可正常使用。

方法一：找回被隔离的文件（推荐）

  1. 打开 360 安全卫士 → 「木马查杀」
  2. 点右下角「恢复区」（或「信任区」→「恢复隔离文件」）
  3. 勾选 EasySSH.exe / EasySSH-x.x.x-portable.exe
  4. 点「恢复并信任」——之后不会再被拦截
  5. 重新运行 EasySSH

方法二：添加信任目录（一劳永逸）

  1. 360 安全卫士 → 「木马查杀」→ 右下角「信任区」
  2. 「添加目录」→ 选择 EasySSH 安装目录（如 P:\Program Files (x86)\EasySSH）
  3. 重新解压/运行下载的文件

方法三：临时退出 360

  1. 右键任务栏 360 图标 → 「退出」
  2. 解压 zip / 运行安装程序
  3. 重新开启 360；首次运行弹窗时选「允许运行」并勾选「不再提醒」

其它安全软件

火绒/腾讯管家等遇到同样提示，操作类似（信任区/白名单）。

向各安全厂商人工提交白名单(误报申诉)指南

若 EasySSH 被您的安全软件误报/拦截,除在软件内提交反馈外,也可按下方渠道向厂商直接申诉。点击入口链接将以弹窗打开。申诉时请附被误报文件的 SHA256(见 SHA256SUMS)与下载地址,联系方式可填写 ad@6xm.net。

360(360 安全卫士/木马查杀)
入口:开放平台「误报申诉」——需注册 360 开发者账号后提交;邮件备用渠道:opensoft@360.cn(附文件名+SHA256+下载地址)。
打开 360 误报申诉入口 →
腾讯电脑管家
入口:腾讯电脑管家官方论坛——在「问题反馈/误报反馈」板块发帖(需论坛账号);客户端内「菜单→反馈」亦可,附 SHA256 与官网下载地址。
打开腾讯电脑管家论坛 →
火绒安全
入口:火绒官方论坛「病毒查杀问题反馈」板块发帖(含「样本误报」子板块)——需论坛账号;管理员会人工复核并加白。
打开火绒样本误报板块 →
微软 Windows Defender / Microsoft Defender
入口:微软安全智能误报提交页——需 Microsoft 账号登录,选择「Software is falsely flagged」并填文件哈希。
打开微软文件提交入口 →
卡巴斯基 Kaspersky
入口:OpenTip 门户——免注册可直接分析哈希;申诉误报需登录 Kaspersky 账号后走 Requests 提交。邮件备用:fp@kaspersky.com(英文说明+SHA256)。
打开 Kaspersky OpenTip →
Dr.Web
入口:样本提交表单——免登录,填文件链接/上传 + 邮箱 + 描述,图片验证码后提交(误报请在描述中说明)。
打开 Dr.Web 样本提交 →
Norton / Avast / AVG / Trend Micro
Norton:误报提交入口 submit.norton.com(选 False positive,可填文件链接);Avast/AVG:邮件 virus@avast.com;Trend Micro:邮件 virus_submission@trendmicro.com(均附 SHA256 与下载地址,联系 ad@6xm.net)。
打开 Norton 误报提交 →
