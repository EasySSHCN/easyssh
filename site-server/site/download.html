# 在线升级（内置，v2.5.0 起）

从 v2.5.0 起，EasySSH 内置加密在线升级，无需再手动回官网下载：

· 自动检测：打开软件后自动探测一次新版本，运行期间每 1 小时自动探测一次；发现新版会在界面顶部标注提醒，也可在「设置 → 检查更新」手工检测。
· 全程加密：检测接口与安装包下载均为加密通道——检测响应为 AES-256-GCM 加密信封并带时效签名，安装包为 AES-256-CTR 加密流，下载后自动解密并做 HMAC-SHA256 + SHA-256 双重完整性校验，校验不过不会落地安装。
· 版本范围：在线升级渠道仅服务 v2.5.0 及以上版本，更早版本请从本页下载安装包升级到 v2.5.0 后即可使用在线升级。

# 开源源代码

EasySSH 以 MIT 协议开源：你可以自由地使用、复制、修改与再分发。 源码包内含全部可运行源代码（main.js / preload.js / renderer.js / assets / package.json 等， 不含 node_modules 依赖与构建产物）。解压后在目录内执行 npm install && npm start 即可从源码运行，开发说明见文档中心与 参与贡献。

⚠ 脱敏说明（SANITIZED）：对外发布的源码包已经过脱敏处理—— 在线升级的真实主密钥文件 update-keys.json 已从源码包中剔除、绝不随源码发布； 源码中保留了脱敏占位样例 update-keys.example.json（内容标注 <REDACTED>）， 相关代码（updater.js / tools/update-crypto.js）文件头均标注了脱敏说明。 自行部署在线升级服务时，请按样例文件内的说明自行生成并保管主密钥。

# SHA256 校验说明

下载完成后建议校验文件完整性。Windows PowerShell 中执行：

Get-FileHash .\EasySSH-<版本号>-win32-x64-portable.zip -Algorithm SHA256

或使用命令行：

certutil -hashfile EasySSH-<版本号>-win32-x64-portable.zip SHA256

对比输出与页面上方卡片中的 SHA256 值一致即可；也可直接下载 SHA256SUMS 清单文件比对（Linux 下可用 sha256sum -c SHA256SUMS）。

# SmartScreen「仍要运行」说明

为什么会有 SmartScreen 提示？
EasySSH 目前未购买代码签名证书。Windows SmartScreen 对所有未签名程序都会提示 「Windows 已保护你的电脑」，这是微软对新发布/未签名文件的通用拦截，并不代表文件有病毒。
如何运行？
解压后首次运行 EasySSH.exe 时如遇 SmartScreen 弹窗，点击「更多信息」→ 出现「仍要运行」按钮 → 点击即可。 同一版本只需确认一次；版本更新后因文件哈希变化会再次提示。
360 等安全软件拦截说明
360 等安全软件对新发布/未签名程序可能弹窗拦截（多为「文件防护」「新文件启发式」）。EasySSH 为开源绿色软件， 不写注册表、不需要管理员权限、不向系统目录写入文件，属常规误报。处理：弹窗时点「允许本次操作」； 或到 360 → 木马查杀 → 信任区 → 添加目录（选择 EasySSH 所在文件夹）一劳永逸。 若文件被误删，请重新下载解压。也可到 360 白名单申诉平台（open.soft.360.cn）提交我们发布的 SHA256 建立云信誉。
安全提示
请务必从本站（easyssh.cn）下载，并通过 SHA256 校验后再运行，谨防第三方渠道的篡改版本。
