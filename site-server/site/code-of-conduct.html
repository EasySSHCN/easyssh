行为准则

与仓库 CODE_OF_CONDUCT.md 保持一致

# 我们的承诺

为营造开放、友好的贡献环境，EasySSH 项目承诺：无论年龄、体型、可见或不可见的残障、族裔、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、个人形象、种族、宗教或性取向如何，所有参与者均不受骚扰。

维护者承诺以开放、包容、专业的态度治理项目。

# 我们的标准

鼓励的行为

  • 使用友好、包容的语言，尊重不同背景与经验水平的贡献者
  • 对他人的贡献给予建设性的反馈，肯定有价值的想法与工作
  • 优雅地接受批评，就分歧聚焦于事实与技术本身
  • 对新人保持耐心，乐于分享知识与经验
  • 报告问题时提供完整、准确的信息，便于他人复现与定位

不可接受的行为

  • 使用性化语言、人身攻击或侮辱性言论
  • 骚扰、挑衅（trolling）或蓄意破坏讨论氛围
  • 公开或私下发布他人的隐私信息（如住址、联系方式）且未经本人同意
  • 在专业场合中被合理认定为不当的其他行为
  • 借项目渠道传播广告、垃圾信息或与项目无关的内容

# 职责

  • 维护者负责澄清行为标准的适用范围，并对不可接受的行为采取适当且公平的纠正措施（警告、临时或永久移除贡献资格等）。
  • 贡献者有义务遵守本准则，并对自己的言行负责。

# 适用范围

本准则适用于项目所有官方空间（代码仓库、Issue、Pull Request、讨论区），也适用于代表项目参加公开场合的行为。

# 申诉与执行

如遭遇或目睹不可接受的行为，请通过项目维护者公布的联系方式（含 SECURITY.md 中的邮箱渠道）报告。所有投诉将及时、公正地审查与处理，报告人的隐私将得到保护。维护者有权对违反本准则者采取其认为适当的措施。

本准则基于 Contributor Covenant（贡献者公约）的精神自撰中文版，并结合 EasySSH 项目实际情况调整。
