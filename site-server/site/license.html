# 第三方组件致谢

EasySSH v5 基于以下开源组件构建，感谢原作者（均为 MIT 或 Apache-2.0/OFL 许可）：

Rust 生态：russh（SSH/SFTP 协议）、tokio（异步运行时）、Tauri 2（应用框架）；前端：xterm.js（终端模拟）及其 Fit/Search 插件；随包工具：MinGit（便携 Git，组件许可文件已随包附带）；字体：Cascadia Code、JetBrains Mono、Sarasa Mono SC、Noto Sans Mono CJK SC（SIL OFL）。

EasySSH
