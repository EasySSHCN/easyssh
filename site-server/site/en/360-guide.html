Guide: Handling 360 False Positives

When downloading or running EasySSH, 360 Total Security may flag or quarantine it (detected as Trojan.Win64.SilverFox). This is a false positive. EasySSH is an MIT-licensed open-source SSH management tool, and a false-positive appeal has been submitted to 360 and is being processed. Use any of the methods below to keep working normally.

Method 1: Restore the quarantined file (recommended)

  1. Open 360 Total Security → "Trojan Scan"
  2. Click "Quarantine Area" at the bottom right (or "Trusted Area" → "Restore quarantined files")
  3. Check EasySSH.exe / EasySSH-x.x.x-portable.exe
  4. Click "Restore and Trust" — it will not be blocked again afterwards
  5. Run EasySSH again

Method 2: Add a trusted folder (once and for all)

  1. 360 Total Security → "Trojan Scan" → "Trusted Area" at the bottom right
  2. "Add folder" → choose the EasySSH installation directory (e.g. P:\Program Files (x86)\EasySSH)
  3. Extract/run the downloaded file again

Method 3: Temporarily exit 360

  1. Right-click the 360 icon in the taskbar → "Exit"
  2. Extract the zip / run the installer
  3. Re-enable 360; on the first-run popup, choose "Allow" and check "Don't remind me again"

Other Security Software

If Huorong/Tencent PC Manager and similar tools show the same alert, the steps are similar (trusted area / whitelist).

Verify on the official site: SHA256 is provided for every file (visible on the download page), so you can compare it against your local file to confirm integrity.
Source code: github.com/EasySSHCN/easyssh (MIT)

Guide: Manually Submitting Whitelist Requests (False-Positive Appeals) to Each Security Vendor

If EasySSH is falsely flagged/blocked by your security software, besides submitting feedback in the app, you can also appeal directly to the vendors via the channels below. Clicking an entry link opens it in a popup. When appealing, please attach the SHA256 of the falsely flagged file (see SHA256SUMS) and the download URL; you may list ad@6xm.net as the contact.

360 (360 Total Security / Trojan Scan)
Entry: the Open Platform's "false-positive appeal" — requires registering a 360 developer account first; email fallback channel: opensoft@360.cn (attach file name + SHA256 + download URL).
Open the 360 false-positive appeal portal →
Tencent PC Manager
Entry: the official Tencent PC Manager forum — post in the "Problem reports / false-positive reports" board (forum account required); the in-app "Menu → Feedback" works too. Attach the SHA256 and the official download URL.
Open the Tencent PC Manager forum →
Huorong Security
Entry: post in the Huorong official forum's "Virus Detection Issue Reports" board (including the "sample false positives" sub-board) — forum account required; moderators will manually review and whitelist it.
Open the Huorong sample false-positive board →
Microsoft Windows Defender / Microsoft Defender
Entry: Microsoft Security Intelligence false-positive submission page — sign in with a Microsoft account, select "Software is falsely flagged", and fill in the file hash.
Open the Microsoft file submission portal →
Kaspersky
Entry: the OpenTip portal — hashes can be analyzed without registration; false-positive appeals require signing in to a Kaspersky account and submitting via Requests. Email fallback: fp@kaspersky.com (English description + SHA256).
Open Kaspersky OpenTip →
Dr.Web
Entry: the sample submission form — no login required; fill in the file link/upload + email + description, complete the image captcha, then submit (mention the false positive in the description).
Open Dr.Web sample submission →
Norton / Avast / AVG / Trend Micro
Norton: false-positive submission portal submit.norton.com (choose False positive; a file link may be provided); Avast/AVG: email virus@avast.com; Trend Micro: email virus_submission@trendmicro.com (attach the SHA256 and download URL to all; contact ad@6xm.net).
Open the Norton false-positive submission →
