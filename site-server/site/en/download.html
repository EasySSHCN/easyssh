# New v5 Engine, All-New Experience (Rust + WebView2 Stable)

EasySSH v5.0 stable upgrades six major areas on top of the new v4 engine:

🔐 Security: mandatory Ed25519 asymmetric signature verification for update manifests (public key fingerprint published on the security policy page), Argon2id key derivation, crash logs kept locally
🛡 Robustness: automatic rollback on failed upgrades (the old version is restored automatically if the new one fails to start), reconnect session state recovery, 15+ integration tests
⚡ Efficiency: SFTP multi-worker pipelined transfers with resume support and optional rate limiting, WebGL terminal rendering, window visible within about 1 second
🧩 Features: terminal split panes (drag to resize / read-only mirrors), global command palette Ctrl+Shift+P (with pinyin filtering), script library macros (variable placeholders + sequential execution), transfer queue pause/resume/priority, port-forwarding rule persistence + one-click batch apply
🎨 Interface: Emerald design system, one-click light/dark theme switching, 34 vector line icons, card-based grouped navigation in Settings

4.x users can upgrade online directly (automatic rollback protection if the upgrade goes wrong); configuration, sessions and the master password are fully compatible — no migration needed.

# Online Updates (Built In, since v2.5.0)

Since v2.5.0, EasySSH ships with a built-in encrypted online updater — no more manual downloads from the website:

· Automatic detection: the app checks for a new version once on launch and then every hour while running; when a new version is found, a reminder badge appears at the top of the UI, and you can also check manually via "Settings → Check for Updates".
· Encrypted end to end: both the update-check API and the installer download run over encrypted channels — the check response is an AES-256-GCM encrypted envelope with time-limited signature, and the installer is an AES-256-CTR encrypted stream that is decrypted automatically after download and verified with dual HMAC-SHA256 + SHA-256 integrity checks; if verification fails, the package is never installed.
· Version range: the online update channel only serves v2.5.0 and above. For earlier versions, download the installer on this page and upgrade to v2.5.0 first, then online updates become available.

# Open Source Code

EasySSH is open source under the MIT License: you are free to use, copy, modify and redistribute it. The source package contains the full runnable source code (main.js / preload.js / renderer.js / assets / package.json, etc., excluding node_modules dependencies and build artifacts). After unzipping, run npm install && npm start in the directory to run from source. For development docs, see the Documentation Center and Contribute.

⚠ SANITIZED notice: the publicly released source package has been sanitized — the real master key file update-keys.json used for online updates has been removed from the source package and is never shipped with the source; the source retains a sanitized placeholder sample update-keys.example.json (with contents marked <REDACTED>), and the related files (updater.js / tools/update-crypto.js) carry sanitization notes in their headers. When deploying your own online update service, generate and store your master key yourself following the instructions in the sample file.

# SHA256 Verification

After downloading, we recommend verifying file integrity. In Windows PowerShell, run:

Get-FileHash .\EasySSH-<版本号>-win32-x64-portable.zip -Algorithm SHA256

Or use the command line:

certutil -hashfile EasySSH-<版本号>-win32-x64-portable.zip SHA256

The output should match the SHA256 value shown in the cards above; you can also download the SHA256SUMS manifest file and compare directly (on Linux, use sha256sum -c SHA256SUMS).

# SmartScreen "Run Anyway" Guide

Why does SmartScreen show a warning?
EasySSH does not currently purchase a code-signing certificate. Windows SmartScreen warns "Windows protected your PC" for every unsigned program. This is Microsoft's generic block for newly released/unsigned files and does not mean the file contains a virus.
How do I run it?
When you first run EasySSH.exe after unzipping, if the SmartScreen dialog appears, click "More info" → a "Run anyway" button appears → click it. You only need to confirm once per version; after a version update, the prompt appears again because the file hash changes.
Blocks by 360 and other security software
Security software such as 360 may pop up a block for newly released/unsigned programs (usually "File Protection" or "New file heuristics"). EasySSH is open-source portable software: it writes nothing to the registry, requires no administrator privileges, and writes no files to system directories — these are routine false positives. What to do: click "Allow this action" on the popup; or add the folder to 360 → Trojan Scan → Trusted Zone (choose the EasySSH folder) once and for all. If the file was wrongly deleted, download and unzip again. You can also submit the SHA256 we publish to the 360 whitelist appeal platform (open.soft.360.cn) to build cloud reputation.
Security tip
Always download from this site (easyssh.cn) and verify the SHA256 before running, to guard against tampered builds from third-party channels.
