Get Started in Three Steps

1 · Download

Download the portable zip, extract it to any directory (avoid system temp directories) and it's ready to use.

2 · Run

On first launch, SmartScreen may warn that the app is unsigned — click "Run anyway" (it will prompt once again after each update).

3 · Connect

Create a session with host/port/username and password. Password, private key, and keyboard-interactive authentication are all supported.
