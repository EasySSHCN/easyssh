检查更新 / 在线升级

功能入口

「⚙ 设置 → 更新」分组中的「检查更新」按钮。

参数说明

  • 升级方式：在线下载升级包，Ed25519 签名校验，失败自动回滚
  • 配置兼容：v4 → v5 配置、会话、主密码完全兼容，升级后自动沿用
  • 便携迁移：也可手动下载绿色 zip 覆盖 exe 所在文件夹
  • 快捷方式：升级完成后自动刷新桌面与快速启动栏快捷方式指向新版

典型用法

  1. 第 1 步：打开「设置 → 更新」，点「检查更新」；
  2. 第 2 步：发现新版本后点「下载并校验」，等待签名校验与安装；
  3. 第 3 步：升级失败会自动回滚到旧版本，无需手动处理；
  4. 第 4 步：首次运行新版本 SmartScreen 提示一次属正常现象。
