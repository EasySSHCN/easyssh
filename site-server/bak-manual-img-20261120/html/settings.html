设置

功能入口

会话工具栏「⚙ 设置」按钮。

参数说明

  • 通用：语言（四语言）、主密码等
  • 外观：主题皮肤、字体字号
  • 编码：终端编码（UTF-8 / GBK / GB18030 等，仅对新建立连接生效）
  • 更新：检查更新与在线升级
  • 快捷方式：桌面/快速启动栏快捷方式手动生成
  • 备份与同步：导出/导入 .esshbak 加密备份、WebDAV 云同步

典型用法

  1. 第 1 步：点「⚙ 设置」打开设置中心；
  2. 第 2 步：左侧分组导航选择分类，右侧修改项；
  3. 第 3 步：多数设置修改即生效并自动保存到 exe 同目录 config.json；
  4. 第 4 步：改编码后请断开重连会话才会生效；
  5. 第 5 步：配置与密钥都随 exe 文件夹携带，拷贝文件夹即完成迁移。
