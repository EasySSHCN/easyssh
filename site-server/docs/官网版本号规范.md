# EasySSH 官网（easyssh.cn）版本号规范

> 内部文档，禁止外泄。制定于 2026-11-17（官网版本 v2.6.0 起）。

## 1. 版本号格式

官网采用语义化版本 **`vX.Y.Z`**（与客户端 EasySSH 软件版本相互独立、互不关联）：

| 位 | 名称 | 何时递增 | 示例 |
|---|------|---------|------|
| **X** | 大版本 | 全站架构级/改版级变更：新站点体系、统一后台上线、全站双语化架构等 | v1→v2（统一后台 admin.html 上线） |
| **Y** | 次版本 | 新功能模块上线（一个批次可含多项功能）；当日功能批次结束即发布一次 | 访客统计标签页、英文版全站、更新记录标签页 |
| **Z** | 修订号 | 缺陷修复、安全加固收尾、样式/文案微调、纯运维维护，不含新功能 | 1.6.1（需求池恢复）、2.4.1（目录合并维护） |

判定规则：当天改动先看是否含**新功能**——有则递增 Y 归零 Z；仅修复/微调则递增 Z；架构级（改变页面组织、数据链路、后台形态）递增 X 归零 Y/Z。一天内可多次发布，每次发布递增一次。

## 3. 数据与展示链路

- **数据源**：`site/assets/data/site-updates.json`（`{current, updatedAt, scheme, versions[]}`），由 `tools/gen-site-updates.js` 从《官网更新历史记录.md》自动生成，**勿手改**。
- **展示位置**：
  - 全站公开页面（含 en/ 英文版）：`assets/js/site.js` 在页脚「© …」版权声明字符串之后追加「官网版本 vX.Y.Z」（英文页「Site version vX.Y.Z」）。
  - 后台管理页 `admin.html`：页脚同样展示版权声明 + 官网版本号；后台页脚**不含任何访客打点信标**，且服务端 `api/visit/track.php` 的 `$excluded` 排除名单拦截 `admin.html`，继续不参与访客统计。
  - 后台「🚀 官网更新记录」标签页（第四标签页）：按版本倒序展示全部更新记录（版本号/日期/摘要/事件明细折叠展开 + 完整分页）。
- **页面 JS/CSS 缓存**：改 `site.js` 后需同步提升引用处缓存版本号（`?v=`）。

## 4. 每次官网更新的维护动作（固定流程）

1. 把本次事件按「标题 + 明细 + 来源」追加进《官网更新历史记录.md》对应日期小节；
2. 按 §1 规则确定新版本号，更新 `tools/gen-site-updates.js` 的 `DATE_VER`/`CURRENT`（新功能日新增日期映射），运行 `node tools/gen-site-updates.js` 重新生成 `site-updates.json`；
3. 部署改动文件到发布机（scp → `tools/deploy.sh`），线上核验页脚版本号与后台更新记录标签页。
