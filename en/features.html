Feature Overview

A lightweight, self-developed SSH/SFTP terminal designed with the SecureCRT experience in mind; 100% original code. (v4 line · continuously enhanced with each release; see the changelog for the latest updates)

# Connections & Sessions

⌨ Multi-Tab SSH Sessions

Manage multiple servers from a single window; password / private key / keyboard-interactive auth auto-adapted; sessions deduplicated and saved by host+port+username.

📥 One-Click Session Import (v5.0.8)

Import sessions in one click from Xshell (reads local .xsh sessions automatically), PuTTY (reads registry SSH sessions automatically), Termius (exported JSON), and OpenSSH config; automatic deduplication, no passwords imported, and automatic grouping by source.

🔑 Key Login & Management

Generate an Ed25519 key pair in one click; one-click public-key installation using a password connection (permission/SELinux fixes + read-back verification); automatic diagnosis of the real cause when key login fails.

🛡 Host Fingerprint Verification

SHA256 fingerprint confirmation on first connection (TOFU), strict comparison afterward; connection is refused with an update prompt when the host key changes — protection against man-in-the-middle attacks.

♻ Automatic Session Recovery

Keepalive prevents idle disconnections; after a disconnect the tab is kept and pressing Enter reconnects automatically; forwarding configuration persists with the session and is restored on reconnect.

⚡ All-New v5.0 Kernel & Security (v5.0.0)

Upgrade manifest Ed25519 asymmetric signature with mandatory verification (public key fingerprint published on the official site), automatic rollback on failed upgrades, Argon2id key derivation, crash logs kept locally — a generational leap in security and reliability.

🪟 Terminal Split Panes & Mirroring (v5.0.0)

Single / left-right / top-bottom / quadrant / custom 1+2 (one large left, two small right, v5.0.8) layouts; draggable dividers to resize panes (persisted); read-only mirror panes; keyboard shortcuts to cycle layouts and switch pane focus.

🎨 All-New Design System (v5.0.0)

Emerald brand color + Design Tokens fully tokenized, one-click light/dark theme switching, 34 vector line icons, card-style grouped navigation in Settings, accessible focus rings, and reduced-motion fallback.

🧩 Efficiency Trio (v5.0.0)

Global command palette Ctrl+Shift+P (filters by pinyin initials), script library macros (variable placeholders + sequential execution), transfer queue pause/resume/priority/rate limiting.

🌐 Networking & Transfer Enhancements (v5.0.0)

SFTP pipelined transfers with multiple workers, resumable transfers (journal survives restarts), optional rate limiting, SOCKS5/HTTP CONNECT proxies, and ProxyJump chains (up to 3 hops reusing stored session credentials).

🚀 Startup Performance (v5.0.0)

Atomic WebView2 data directory switching + background cleanup, windows visible within about 1 second; hardened upgrade completion sequence (wait for the old process to exit → auto-launch the new version → automatic rollback on failure).

🔄 Smart Auto-Reconnect (v4.3.1)

Unexpected disconnects retry automatically 3 times with 2/4/8-second exponential backoff; press Enter to take over at any time; single-instance operation so double launching no longer corrupts the configuration.

🌐 Multi-Encoding Support

UTF-8 / GBK / GB18030 / Big5 with automatic and manual detection — no more garbled output from misencoded servers; encoding settings remembered per session.

📦 Portable · Seamless Upgrades

Extract and run: no registry writes, no administrator privileges, and the whole folder can be copied elsewhere and used as-is; 3.x configurations upgrade in place seamlessly.

# Terminal Experience

⇅ Toolbar/Quick-Command Bar Collapse (v5.0.12)

A slim toggle below the quick-command bar collapses the function row and quick-command row in one click, letting the terminal fill the freed space; arrows always visible with hover highlight; state persisted across restarts; stacks with sidebar collapse for a maximized terminal area.

⇔ One-Click Sidebar Collapse/Expand (v5.0.10)

Click the slim strip between the session list and the terminal area to collapse the left sidebar in one click, instantly letting the interactive terminal fill the whole window; click again to expand, with the arrow rotating to reflect state; collapsed state is remembered across restarts; terminal panes and split layouts automatically re-fit to fill the space.

🖥 Modern Terminal Kernel

xterm.js rendering, window-resilient layout, 256 colors, remembered window size; output pushed in 16ms frame-batched chunks plus early push at a 32KB threshold — no dropped frames under high-frequency output; UTF-8 multi-byte protection across batches prevents garbled text (v4.3.0/v4.3.1).

🔍 In-Terminal Search

A keyboard shortcut opens the search bar within a session to locate key log lines upward / downward.

⚡ Quick Command Bar

Custom buttons for frequently used commands sent in one click; add / edit / delete supported.

🎨 5 Skin Themes

Global switching between light and dark palettes; the custom-drawn title bar follows the theme.

🗣 Multi-Language UI (v5.1.4)

Simplified Chinese (default) / Traditional Chinese / English / 한국어; one-click switching takes effect instantly. v5.1.4: your language is remembered across restarts; UI translations greatly expanded (toolbar, quick commands, all nine settings groups — 439 entries); switching applies instantly, including back to Chinese.

📋 Smart Clipboard

Copy on selection, paste on right-click; terminal title spoofing prevented (OSC injection is escaped at the rendering layer).

# File Transfer (SFTP)

📁 Remote File Management

Remote directory browsing, rename, delete, create directory, right-click context menu, and direct path navigation.

⬆ Upload / Download Queue

Multi-task transfer queue with real-time progress and cancellation; text encoding conversion during transfer based on the server's encoding.

📂 Whole-Directory Download

Recursively download remote directories to your local machine, automatically recreating the same directory structure.

🚀 Transfer Performance

256KB chunked streaming transfers + throttled progress events (100ms or ≥1% increments) keep the UI responsive during large-file transfers (v4.3.0).

🛡 Hardened Transfer Channel (v4.3.1)

SFTP channels isolated per session (multi-tab interference eliminated) + self-healing channels after reconnect + recursive directory deletion; a 4-concurrency gate keeps bulk transfers from hogging bandwidth.

☑ Multi-Select Batch Operations (v4.3.2)

Select multiple files and directories with checkboxes / Ctrl / Shift; a single click toggles selection (no Ctrl needed) + Shift range selection; right-clicking a multi-selection shows only batch-capable actions: batch download (unified target directory, recursive) and batch delete (recursive per item, summarized results) (v4.3.3; v4.3.4 fixed the properties API; v4.3.7 adds dynamic file naming after upgrades + automatic desktop shortcut updates).

ℹ Properties & Directory Size Calculation (v4.3.2)

Right-click "Properties" in Windows Explorer style (full properties for single selection / aggregated stats for multiple); right-click a directory and "Calculate Size" recursively totals disk usage (depth/entry caps prevent runaway scans; unreadable entries skipped automatically), with results written back into the list (v4.3.3; v4.3.4 fixed the properties dialog).

# Networking & Forwarding

🔀 Local Port Forwarding

127.0.0.1:local port → target host:target port; configuration persists with the session and is restored automatically on reconnect.

🧦 SOCKS 4/5 Dynamic Forwarding (fixed in v5.0.13)

Turn a local port into a SOCKS proxy over an encrypted SSH tunnel (since v2.8.1); fixes an issue since v5.0.8 where dynamic+socks fields appearing together caused a startup error (duplicate field `socks`); all previously saved forwarding records remain fully compatible with zero migration.

# Keys & Security

🔒 Master Password Protection

Optional to enable; keys are wrapped on disk with a derived key + AES-256-GCM, with a full-screen unlock at startup; automatically locked after 5 consecutive wrong attempts.

🧮 Hardened Derivation (v4.3.0)

Master password derivation iterations raised from 100K to 600K (OWASP 2023 recommendation); fully backward compatible with old data, transparently migrated on first unlock.

🧬 Argon2id Derivation (v4.3.1)

New master password writes upgraded to Argon2id (wrap:v3, m=64MiB/t=3/p=1); v1/v2/v3 formats all remain readable, with old data migrated progressively.

🔐 Keys Bound to This Machine (v4.3.1)

config.key on disk is now bound to the current Windows user via DPAPI; configurations copied to another machine cannot be decrypted; old plaintext keys upgrade transparently, with an explicit notice when switching machines.

🧱 Content Security Policy (v4.3.1)

CSP tightened to script-src 'self', inline scripts externalized, and injection defenses for remote output strengthened.

💾 Configuration Reliability (v4.3.0)

config.json written atomically with automatic retention of the last 5 rolling backups, so power loss / crashes never lose your configuration; key file writes are atomic; automatic fallback to a backup when startup reads fail (v4.3.1).

🔐 Encrypted Storage

Session passwords / passphrases are written to config.json encrypted with AES-256-GCM (enc:v1); without the master password enabled they cannot be decrypted.

# Upgrades & Maintenance

🔐 Secure Online Upgrades

Update-check API with AES-256-GCM envelope + time-limited HMAC signatures (anti-tampering / anti-replay); the installer is downloaded as an encrypted stream with dual HMAC + SHA-256 verification — any failure aborts the install before anything touches disk.

♻ Seamless In-Place Upgrade

The old exe is renamed to .bak → the new version takes over the original name → launched detached, with shortcuts carrying over seamlessly; automatic rollback to the old version if any step is blocked; leftover backups are cleaned up automatically at startup.

⭐ Desktop / Quick Launch Shortcuts (v5.0.9)

Settings → Shortcuts lets you manually generate desktop shortcuts and Quick Launch (taskbar pinned area) shortcuts in one click, with same-name overwrite updates and safe repeated clicks; after an online upgrade both shortcut types are automatically refreshed to point to the new version.

🧹 Cache Self-Healing

Old WebView2 caches are cleaned automatically when the version changes (triple safeguards: no-store response header + Rust startup-layer marker comparison + in-app cleanup), so after an upgrade you always run the brand-new UI.

📮 User Feedback

Submit issue feedback in one click from within the app (diagnostic info optional), straight to the development team.

📊 Anonymous Usage Statistics (v5.1.0)

One anonymous statistics report is uploaded in the background on each day's first launch (OS / CPU / memory-disk tier / language / region), with device identifiers SHA-256 de-identified; no hostname, MAC address, or full IP or other identity information, used for statistics only; can be turned off anytime under Settings → Upgrade → Privacy.

🛡 Unified Admin Backend (v5.1.0)

easyssh.cn/admin.html is the unified entry point: the client statistics dashboard (device count / activity trends / version & hardware distribution) and user feedback management share one authenticated login; feedback-admin redirects automatically to the new address.

# Usage (Portable, No Installation)

    # Known Limitations

    • The master password is an optional feature: when not enabled, decryption keys are stored alongside the program directory (protects against accidental propagation, not direct local reads); if security matters to you, be sure to enable the master password in "Settings" (600K-iteration derivation since v4.3.0).
    • The exe is not code-signed, so SmartScreen will prompt once on first run (see the download page notes).
    • Encoding settings only take effect for newly created connections.
